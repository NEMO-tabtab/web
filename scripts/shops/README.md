# 가챠샵 목록 채우기

지도에 싣는 가챠샵(`public/shops/index.json`)을 공공데이터에서 뽑아 사람이 검수한 뒤 넣는 방법입니다.
방향은 [결정 기록 0004](../../docs/decisions/0004-map-and-indoor-map.md)의 "공공데이터를 쓰는 곳"을 따릅니다.

## 순서

1. **자료 받기** — 공공데이터포털의 [소상공인시장진흥공단_상가(상권)정보](https://www.data.go.kr/data/15083033/fileData.do)에서 파일을 내려받아 압축을 풉니다. 로그인·인증키 없이 받을 수 있고, 이용허락범위는 "제한 없음"입니다(2026-11-23 확인). 분기마다 새로 나옵니다. 시도별 CSV이며 저장소에는 넣지 않습니다(전체 약 1.5GB).
2. **후보 뽑기**

   ```bash
   node scripts/shops/find-candidates.mjs find <받은 폴더>/소상공인시장진흥공단_상가(상권)정보_서울_202609.csv
   ```

   상호에 가챠·갓챠·가차·가샤폰·캡슐토이·gacha·gashapon이 들어 있고 업종 대분류가 소매 또는 예술·스포츠인 곳을 `scripts/shops/candidates.json`에 합칩니다. 이미 검수한 후보는 건드리지 않습니다.
3. **검수** — `candidates.json`에서 후보마다 `review`를 고칩니다.

   | 값 | 뜻 |
   |---|---|
   | `todo` | 아직 안 봄 |
   | `ok` | 영업 중이고 가챠 기기가 있다. 지도에 싣는다 |
   | `no` | 싣지 않는다. `note`에 까닭을 적는다(폐업, 가챠 기기 없음, 다른 후보와 같은 곳) |

   이름·주소·층(`floorNote`)이 실제와 다르면 이 파일에서 고칩니다. `category`·`building`은 검수할 때 참고하라고 둔 값이고 지도에는 쓰지 않습니다.
4. **싣기**

   ```bash
   node scripts/shops/find-candidates.mjs apply
   pnpm test
   ```

   `ok`인 후보가 `public/shops/index.json`에 더해집니다. 이미 목록에 있는 굿즈샵은 건드리지 않습니다.

## 알아 둘 것

- 후보는 상호만 보고 고른 것입니다. 폐업한 곳, 이름만 가챠인 곳이 섞여 있으므로 검수하지 않은 후보는 지도에 싣지 않습니다.
- 상호에 위 낱말이 없는 곳(대형 쇼핑몰 안의 가챠 코너, 제조사 직영점 등)은 뽑히지 않습니다. 이런 곳은 `candidates.json`에 손으로 더합니다. `id`는 영문 소문자·숫자·하이픈으로 짓습니다.
- 굿즈샵 `id`는 상가업소번호에서 만듭니다(`sb-…`). 다시 뽑아도 같아서, 사용자의 기록이 가리키는 굿즈샵이 바뀌지 않습니다. 한 번 지도에 실은 `id`는 바꾸지 않습니다.
- 새 자료에 없는 기존 후보는 "이번 자료에 없음"으로 알려 줍니다. 폐업했는지 확인해 `no`로 바꾸고, 지도에서 내릴지는 따로 정합니다.
