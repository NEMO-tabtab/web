# 가챠 카탈로그 입력 안내

팀이 가챠의 작품·시리즈·종류를 손으로 입력하는 방법입니다. 이 데이터로 도감("6종 중 4종"), 빠른 등록, 사진으로 가챠 찾기를 만듭니다.
결정 배경은 #165, 형식의 정의는 `src/lib/shops/schema.ts`(`seriesListSchema`, `titleListSchema`)입니다.

## 꼭 지킬 것

1. **공식 사이트를 자동으로 긁어 오지 않는다.** 반다이 가샤폰 사이트는 사전 허락 없는 자동 수집과 AI 이용을 금지한다. 페이지를 보고 사실(이름, 종류 수, 가격, 종류 이름)만 손으로 적는다.
2. **이미지는 넣지 않는다.** 저장소가 공개이고, 이미지 사용 권리를 확인하지 않았다.
3. **머지하면 운영 앱에 바로 공개된다.** `public/`의 파일은 그대로 사용자에게 내려간다.
4. **id는 한 번 정하면 바꾸지 않는다.** 사용자의 기록이 작품·시리즈·종류 id를 가리킨다. 지우거나 바꿔야 하면 먼저 팀에 알린다.

## 파일

| 파일 | 담는 것 |
|---|---|
| `public/shops/titles.json` | 작품(애니메이션, 브랜드 등) |
| `public/shops/series.json` | 시리즈와 그 안의 종류(라인업) |
| `public/shops/machines/{굿즈샵}.json` | 매장의 어느 기기에 어느 시리즈가 들어 있는지(굿즈샵 데이터, `docs/decisions/0004`) |

## 순서

1. 작품이 `titles.json`에 없으면 먼저 넣는다.
2. `series.json`에 시리즈를 넣는다.
3. `pnpm test`로 확인한다. 틀리면 어느 파일의 어디가 왜 틀렸는지 나온다.
   ```
   "series.json series.0.releasedAt: 발매 월은 2026-11 처럼 적는다",
   "series.json: jujutsu-kaisen-capsule-2: 종류 id 가 겹친다",
   ```
4. PR을 연다(`feat: 카탈로그에 ○○ 시리즈 추가`). 확인한 출처를 시리즈의 `sources`에 적는다.

## id 만드는 법

영문 소문자, 숫자, 하이픈(`-`)만 쓴다.

| 대상 | 예 |
|---|---|
| 작품 | `jujutsu-kaisen` |
| 시리즈 | `jujutsu-kaisen-capsule-figure-2` (작품-시리즈-번호) |
| 종류 | `gojo`, `secret` (시리즈 안에서만 겹치지 않으면 된다) |

## 작품 칸 (`titles.json`)

| 칸 | 필수 | 뜻 | 예 |
|---|---|---|---|
| `id` | 필수 | 위 규칙 | `"jujutsu-kaisen"` |
| `name` | 필수 | 한국에서 부르는 이름 | `"주술회전"` |
| `aliases` | 선택 | 다른 이름(원제, 영어). 검색과 사진 글자 인식에 쓴다 | `["呪術廻戦", "Jujutsu Kaisen"]` |

## 시리즈 칸 (`series.json`)

| 칸 | 필수 | 뜻 | 예 |
|---|---|---|---|
| `id` | 필수 | 위 규칙 | `"jujutsu-kaisen-capsule-figure-2"` |
| `name` | 필수 | 한국어 시리즈 이름 | `"주술회전 캡슐 피규어 vol.2"` |
| `price` | 선택 | 한국에서 1회 돌리는 값(원). 모르면 비운다. 아래 "가격" 참고 | `4000` |
| `priceShops` | 선택 | `price`를 평균 낸 가게 수 | `3` |
| `priceJpy` | 선택 | 공식 일본 가격(엔, 세금 포함) | `400` |
| `titleId` | 선택 | 작품 id | `"jujutsu-kaisen"` |
| `aliases` | 선택 | 대지·공식 페이지에 적힌 다른 이름. **사진 글자 인식은 이 이름으로 찾는다** | `["呪術廻戦 カプセルフィギュア2"]` |
| `maker` | 선택 | 제조사 | `"반다이"` |
| `kind` | 선택 | `"gacha"`(캡슐), `"blindbox"`(블라인드 박스), `"goods"`(그 밖의 콜라보 굿즈). 비우면 가챠 | `"gacha"` |
| `releasedAt` | 선택 | 발매 월 | `"2026-11"` |
| `lineup` | 선택 | 종류 목록. **비우면 도감에서 셀 수 없다** | 아래 |
| `sources` | 선택 | 값을 확인한 곳 | `["https://…", "홍대 ○○샵 대지"]` |
| `checkedAt` | 선택 | 마지막으로 확인한 날 | `"2026-11-23"` |

종류(`lineup`의 한 칸):

| 칸 | 필수 | 뜻 |
|---|---|---|
| `id` | 필수 | 시리즈 안에서 겹치지 않는 id |
| `name` | 필수 | 종류 이름. 시크릿 이름을 모르면 `"시크릿"` |
| `secret` | 선택 | 시크릿(스페셜)이면 `true` |
| `odds` | 선택 | **회사가 밝힌 확률만** 0~1 사이 소수로. 1/24 → `0.0417` |

## 가격

- `price`는 한국 가게에서 본 1회 가격의 **평균**이다(#165). 원 단위 정수로 반올림하고, 평균 낸 가게 수를 `priceShops`에 적는다.
- 새 가게에서 값을 보면: 새 평균 = (지금 평균 × 가게 수 + 새 값) ÷ (가게 수 + 1), `priceShops`는 1 늘린다.
- 공식 일본 가격은 `priceJpy`에 따로 적는다. 엔화를 원으로 바꿔 `price`에 넣지 않는다.
- 한국 가격을 아직 모르면 `price`를 비운다. 0을 넣지 않는다 — 화면에 0원으로 보인다. 비어 있으면 화면은 값을 그리지 않는다(#237).

## 확률

- 회사가 밝힌 확률만 `odds`에 적는다. 밝히지 않은 종류는 비운다.
- 비운 종류끼리는 남은 확률을 똑같이 나눈다. 아무것도 적지 않으면 모두 1/n이다. 앱은 이 값을 "추정"으로 표시한다(#165).
- 모든 종류에 적었으면 합이 1이어야 한다(0.01 오차 허용). 일부만 적었으면 합이 1보다 작아야 한다.

## 예

형식을 보여 주는 예다. 실제 값이 아니다.

```json
{
    "id": "jujutsu-kaisen-capsule-figure-2",
    "name": "주술회전 캡슐 피규어 vol.2",
    "price": 4000,
    "priceShops": 3,
    "priceJpy": 400,
    "titleId": "jujutsu-kaisen",
    "aliases": ["呪術廻戦 カプセルフィギュア2"],
    "maker": "반다이",
    "kind": "gacha",
    "releasedAt": "2026-11",
    "lineup": [
        { "id": "gojo", "name": "고죠 사토루" },
        { "id": "itadori", "name": "이타도리 유지" },
        { "id": "secret", "name": "시크릿", "secret": true }
    ],
    "sources": ["https://공식-페이지-주소", "홍대 ○○샵 대지"],
    "checkedAt": "2026-11-23"
}
```

`public/shops/series.json`의 `(예시)` 시리즈 두 개(`virtual-cats`, `virtual-bread`)가 실제로 들어가 있는 예입니다. `virtual-bread`는 시크릿 확률만 알려진 경우입니다.
