# 0003. AI 에이전트 지침은 짧은 CLAUDE.md + 작업별 문서

날짜: 2026-11-15 / 상태: 확정

## 결정

- `CLAUDE.md`는 하나만 두고 50줄 안팎으로 유지한다. 내용은 "항상 지킬 것 몇 줄"과 "어떤 작업에 어떤 문서를 읽을지" 표뿐이다.
- 규칙 본문은 `docs/`의 주제별 문서에 두고, 에이전트는 작업에 해당하는 문서만 읽는다.

## 이유

`CLAUDE.md`는 세션마다 통째로 읽힌다. 커지면 매번 비용이 들고 중요한 줄이 묻힌다는 걱정은 맞다. 다만 파일을 여러 개의 지침 파일로 쪼개는 것보다, 지침 파일은 입구로만 쓰고 본문을 `docs/`에 두는 편이 낫다. 사람과 에이전트가 같은 문서를 읽으므로 내용이 두 벌이 되지 않는다(원칙 P6).

## 버린 대안

- 규칙을 `CLAUDE.md`에 모두 적기: 커지고, `docs/`와 내용이 갈린다.
- `AGENTS.md`를 함께 두기: 지금 쓰는 도구가 하나라 같은 내용이 두 벌이 된다. 다른 도구를 쓰게 되면 `CLAUDE.md`를 가리키는 한 줄짜리로 추가한다.

## 다시 볼 때

`CLAUDE.md`가 80줄을 넘거나, 특정 폴더에서만 필요한 지침이 생기면 경로별 규칙 파일(`.claude/rules/`)로 나누는 것을 검토한다.
