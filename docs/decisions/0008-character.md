# 0008. 캐릭터: 네모는 기록 상자, 짝은 캡슐 친구 동글

날짜: 2026-11-25 / 상태: 방향 확정, 구현 중 (묶음 이슈 #222)

## 결정

- **네모는 "기록 상자"다.** 뽑은 것을 담아 두고 전부 기억하는, 살아 있는 작은 종이 상자. 앱이 하는 일(담기·기억하기·찾기)이 그대로 네모의 성격이다.
- **짝은 캡슐 친구 "동글"이다.** 네모가 기억을 맡고 동글이 설렘을 맡는다. 동글은 말을 하지 않는다. 화면의 화자는 네모 하나다.
- **그림의 기준은 정면에서 본 네모다.** 화면과 앱 아이콘은 정면만 쓴다. 큰 그림에는 윗면과 옆면을 덧붙인 입체 보기를 쓴다.
- **그림의 원본은 한 곳(`src/lib/nemo`)에 둔다.** 표정과 자세는 정해진 것만 쓰고, 새로 필요하면 원본에 더한다.
- 이름은 지금처럼 "네모"다. 캡슐 친구의 이름은 "동글"이다(2026-11-25에 그림을 보고 정함. 코드에서는 `capsule`로 부른다).

## 네모

| | |
|---|---|
| 정체 | 뽑은 것을 담아 두는 종이 상자. 머리 위에 종이테이프가 붙어 있다 |
| 한마디 | "뽑은 건 네모가 다 기억해요." |
| 크기 | 손바닥에 올라오는 크기. 캡슐보다 조금 크다 |
| 성별·나이 | 정하지 않는다 |
| 좋아하는 것 | 처음 보는 종류, 줄 맞춰 세우기, 테이프, 달그락 소리 |
| 무서워하는 것 | 물과 비(종이라서), 구겨지는 것, 잊어버리는 것 |

**성격 다섯 가지.** 그림과 문구는 여기에서 나온다.

1. **순하다.** 작은 것에 크게 기뻐한다. 비꼬거나 빈정대지 않는다.
2. **궁금해한다.** 새 물건은 흔들어 소리부터 듣는다. "안에 뭐가 들었을까요?"
3. **잘 기억한다.** 한 번 담은 것은 잊지 않는다. 그래서 같은 것이 또 나오면 바로 알아본다. 네모의 자랑이다.
4. **혼자서도 논다.** 기다리는 동안 모은 것을 줄 세우고 캡슐을 굴린다. 빈 화면과 기다리는 화면의 그림이 여기서 나온다.
5. **엉뚱하게 진지하다.** 사소한 일에 격식을 차린다. 같은 것이 또 나오면 "짝꿍"이라 부르고, 백 번째 기록에는 혼자 박수를 친다.

**기분은 테이프에 드러난다.** 얼굴은 덤덤하다(・ω・). 놀라면 테이프가 쫑긋 서고, 풀이 죽으면 축 처지고, 신나면 펄럭인다.

**몸이 곧 하는 일이다.** 뚜껑을 열어 담고, 속을 들여다보며 찾고, 끈으로 묶어 백업한다. 일이 잘못되면 한쪽이 구겨진다.

## 캡슐 친구 — 동글

- 네모가 맨 처음 담은 캡슐. 안에 뭐가 들었는지는 아무도 모른다. 자기도 모른다.
- 가만히 있지 못한다(구르고 튄다). 감탄이 빠르고 금방 잊는다. 다 기억하는 네모와 반대다.
- 말을 하지 않는다. 소리(딸깍, 데굴)와 몸짓만 낸다.
- 실제 가챠 캡슐처럼 아래쪽 그릇과 위쪽 뚜껑 두 쪽이다. 얼굴은 그릇에 있고, 눈과 볼은 네모와 같은 모양이며 입만 다르다.
- 팔다리가 없다. 기분은 뚜껑 틈에 드러난다(닫힘·들썩·열림).
- 나오는 자리: 뽑는 순간, 가챠샵과 지도, 기다리는 화면(구르는 캡슐), 네모와 함께 있는 큰 그림.

## 말투

화면 문구 규칙([design-system.md](../design-system.md)의 U7)을 그대로 따르고, 그 위에 네모의 것을 더한다.

- 네모는 자신을 "네모"라고 부른다. "제가", "저는"이라고 하지 않는다. 지금 문구 "첫 물건을 네모에게 보여주세요!"와 같은 결이다.
- 한 번에 한 문장. 실패했을 때는 다음에 할 일을 붙인다(U7).
- 감탄은 소리말 한 낱말로 한다: 달그락(담겼을 때), 딸깍(캡슐), 삑(바코드), 찰칵(사진), 꾹(도장).
- 느낌표는 정말 기쁜 일에만 쓴다.

| 순간 | 견본 |
|---|---|
| 빈 목록 | 네모 속이 아직 비어 있어요. 첫 물건을 보여 주세요. |
| 새 종류 | 달그락! 처음 보는 종류예요. |
| 같은 종류가 또 나옴 | 짝꿍이 생겼어요. |
| 검색 결과 없음 | 네모가 다 뒤져 봤는데 없어요. 다른 낱말로 찾아볼까요? |
| 불러오지 못함 | 앗, 네모가 놓쳤어요. 잠시 뒤 다시 시도해 주세요. 기록은 그대로예요. |
| 오프라인 | 지금은 인터넷이 없어요. 기록해 둔 물건은 네모가 그대로 갖고 있어요. |
| 백업 완료 | 꼭꼭 싸 뒀어요. 저장한 곳을 기억해 두세요. |

견본은 말투를 보이기 위한 것이다. 화면 문구를 바꾸는 일은 따로 이슈로 한다.

**하지 않는 말**

- 더 뽑으라는 말, 확률이나 돈으로 부추기는 말. 네모는 기록하는 친구이지 뽑기를 권하는 친구가 아니다.
- 탓하거나 놀리는 말. 같은 것이 또 나와도 놀리지 않는다.
- 오지 않으면 서운하다는 말. 출석은 누르는 것 없이 조용히 찍힌다(#179).
- 이모지(U4).

**네모의 목소리는 볼터치 색처럼 아껴 쓴다.** 빈 화면, 기쁜 순간, 기다림, 가벼운 실패에만 쓴다. 삭제 확인, 권한 요청, 개인정보 안내는 지금처럼 꾸밈없는 문장으로 쓴다.

## 그림의 원칙

구현할 때 아래에서 벗어나면 이 문서를 고치는 PR을 먼저 올린다.

- **기준은 정면이다.** 지금의 `NemoFace`(120칸, 살짝 기운 몸)를 기준 그림으로 삼는다.
- **심볼(로고, 앱 아이콘)도 같은 몸이다.** 전신에서 팔다리만 덜어 내고 몸·테이프·얼굴은 그대로 쓴다. 다른 것은 선 굵기 하나다(24px까지 내려가므로 한 단계 굵게).
- **입체는 정면에 덧붙인다.** 정면 그림을 그대로 두고 윗면과 옆면을 뒤로 붙인다. 얼굴이 놓인 면이 같아서 표정을 한 벌만 그린다. 160px보다 작은 자리에는 쓰지 않는다.
- **얼굴은 덜어 낸 채로 둔다.** 점 눈 두 개, ω 입, 볼 두 점이 기본이다. 표정은 눈과 입의 모양, 테이프, 몸의 기울기, 작은 표시(땀방울·반짝·물음표)로 만든다. 눈썹과 그림자는 그리지 않는다.
- **팔다리는 먹선 한 획이다.** 손은 그리지 않는다. 소품은 획 끝에 붙는다.
- **색은 먹·종이·볼터치다.** 입체 보기의 옆면과 열린 상자의 안쪽처럼 물러난 면에만 `cream`을 쓴다. 캐릭터를 다른 색으로 칠하지 않는다. 볼 색만 사용자가 모은 색으로 바뀔 수 있다(#153).
- **작은 자리에서는 덜어 낸다.** 64px 이하에서는 소품과 표시를 빼고 표정으로만 말한다. 40px 이하에서는 작은 필터를 쓰고, 24~32px에는 심볼을 쓴다.
- **손떨림은 필터가 낸다.** 패스는 곧게 그리고 `src/app/layout.tsx`의 `#rough-line` 필터가 흔든다. 그리기 라이브러리를 더하지 않는다(0004와 같다).
- **소품은 실제를 닮게 그린다.** 캡슐과 가챠 기기는 실제 모양을 확인하고 그린다.
- **원본은 한 곳이다.** 치수·색·획은 `src/lib/nemo`에 두고, 화면은 캐릭터 부품으로만 그린다. 문서 화면(`/design-system/character`)은 원본의 목록을 돌며 그린다.

## 처음 만드는 그림

앱에 실제로 있는 순간에서 뽑았다. 구현한 뒤에는 `src/lib/nemo`의 목록이 원본이고, 이 표는 고치지 않는다.

| 표정 | 쓰는 순간 |
|---|---|
| 기본 | 홈 인사 카드, 프로필, 심볼 |
| 기대 | 빈 목록 |
| 기쁨 | 저장·가입·가져오기를 마쳤을 때 |
| 신남 | 새 종류, 새 시리즈(#202) |
| 담담 | 같은 종류가 또 나왔을 때 |
| 깜짝 | 바코드를 읽었을 때, 이미 등록한 물건일 때 |
| 갸웃 | 검색 결과가 없을 때, 바코드 정보를 못 찾았을 때 |
| 집중 | 스캔하는 중, 찾는 중, 여는 중 |
| 뿌듯 | 백업을 마쳤을 때, 시리즈를 다 모았을 때 |
| 찡긋 | 확인, 고마움 |
| 머쓱 | 불러오지 못했을 때 |
| 졸림 | 오프라인, 준비 중, 서버가 깨어나는 중 |

- 자세 12개: 서 있기, 인사, 텅(뚜껑을 열고 빈 속을 보인다), 담기, 찾기(돋보기), 삑(바코드 라벨), 찰칵(카메라), 길 찾기(지도), 꼭꼭 싸기(끈으로 묶은 꾸러미 — 백업), 만세, 구겨짐, 잠.
- 테이프 4가지: 기본, 쫑긋, 축, 펄럭. 몸 2가지: 뚜껑 열림, 구겨짐.
- 동글의 표정 6개: 기본, 들썩, 열림, 데굴, 시무룩, 쿨쿨.
- 둘이 함께 있는 장면 3개(입체): 나란히, 담기, 나들이.

## 쓰는 자리

규칙은 [design-system.md](../design-system.md)의 U8에 있다. 여기에는 까닭을 적는다.

- 네모는 정서가 있는 순간에만 선다(비었을 때, 기쁠 때, 기다릴 때, 가볍게 실패했을 때). 볼터치 색을 정서적 강조에만 쓰는 것과 같은 까닭이다. 늘 보이면 아무 뜻도 전하지 못한다.
- 한 화면에 한 번만 선다. 물건 카드처럼 여러 장이 한꺼번에 나오는 자리에는 세우지 않는다.
- 삭제 확인, 권한 요청, 개인정보 안내에는 세우지 않는다. 사용자의 판단을 캐릭터의 표정으로 흔들지 않는다.
- 상황은 문장이 전한다. 캐릭터는 화면 낭독기가 읽지 않으므로, 캐릭터가 없어도 문장만으로 상황을 알 수 있어야 한다.

## 이유

- 이 앱은 물건을 담고, 기억하고, 찾는 앱이다. 캐릭터가 같은 일을 하는 존재이면 캐릭터를 따로 설명할 필요가 없고, 기능이 늘 때 그릴 자세가 기능에서 바로 나온다.
- 성격의 참고는 어드벤처 타임의 비모다. 가져온 것은 구조다: 기기이면서 친구라는 것(기능이 곧 개성), 덤덤한 얼굴과 풍부한 속마음, 혼자 있을 때의 놀이, 아이 같은 진지함. 생김새와 설정, 대사는 가져오지 않는다.
- 얼굴을 덜어 내면 적은 부품으로 많은 표정을 만들 수 있고 24px에서도 뭉개지지 않는다. 먹선과 색 하나라는 디자인 시스템과도 맞는다.
- 가챠는 돈이 드는 취미다. 캐릭터가 뽑기를 권하면 앱이 소비를 부추기게 된다. 그래서 네모는 뽑은 뒤의 일(기록)을 맡고, 설렘을 맡은 캡슐 친구는 말을 하지 않는다.
- 정면을 기준으로 둔 까닭: 이미 앱 아이콘과 스토어에 나가 있고, 선이 적어 작은 크기에서 또렷하다. 입체를 정면에 덧붙이면 두 보기의 얼굴이 어긋날 수 없다.
- 캡슐을 짝으로 고른 까닭: 초안의 둥근 뽑기 기계는 실제 가챠샵의 네모난 캡슐 기기와 모양이 다르다. 캡슐은 어느 가챠에서나 나오고, 네모난 몸과 모양이 대비된다.

## 버린 대안

- 네모를 "가챠에서 나온 친구"(자기 안에 뭐가 들었는지 모르는 상자)로: 뽑는 설렘에 무게가 실려 기록이라는 앱의 중심과 멀다. 이 성격은 캡슐 친구에게 주었다.
- 설정 없이 성격과 말투만 정하기: 가볍지만 자세와 문구를 정할 기준이 없다.
- 초안처럼 입체 상자를 기준 그림으로: 작은 크기에서 선이 뭉개지고, 앱 아이콘·로딩 화면·스토어 그림을 모두 다시 올려야 한다.
- 로고만 둥근 몸으로 두기(지금까지의 로고): 앱 아이콘과는 닮았지만 전신과 모서리·눈 간격이 달라 한 캐릭터로 보이지 않는다. 둥근 몸에 전신의 얼굴만 넣는 절충안도 그려 보았고(2026-11-25), 전신의 몸을 그대로 쓰는 쪽으로 정했다.
- 초안의 둥근 뽑기 기계를 그대로: 실제 기기와 모양이 다르다.
- 동글의 아래쪽 반을 `cream`으로 칠하기: 그려 보니(2026-11-25) 흰 바탕에서도 거의 구분되지 않았다. 얻는 것이 없고, `cream`은 물러난 면에만 쓴다는 규칙이 흐려진다.
- 네모가 반말로 말하기: 화면 문구 규칙(U7)과 말투가 둘로 갈린다.
- 손으로 흔들리게 그린 패스, 그리기 라이브러리: 0004에서 필터로 정했다.

## 확인이 남은 것

- 네모와 동글의 실제 크기. 흔한 캡슐은 지름 48~50mm이고 큰 것은 79~90mm라는 2차 자료를 찾았다(2026-11-25). 제조사의 공식 규격표로는 확인하지 못했다. 그림에서는 동글의 지름을 네모 몸 너비의 0.57배로 그렸다.

## 나중으로 미룬 것

- 화면에 표정과 자세를 적용하는 일(빈 화면마다 다른 얼굴, 오류, 기다림, 바코드, 백업, 가입, 없는 주소)과 화면 문구를 네모 말투로 바꾸는 일(#195).
