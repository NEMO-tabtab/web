# 0002. 리뷰는 위험 영역에만 1명

날짜: 2026-11-15 / 상태: 확정

## 결정

- 일반 PR: 승인 없이, 미리보기 빌드가 성공하면 본인이 머지한다.
- [위험 영역](../production.md#위험-영역) PR: 다른 1명이 승인해야 머지한다.

## 이유

팀이 3명이라 모든 PR에 승인을 요구하면 기다리는 시간이 길어진다. 리뷰 시간을 되돌리기 어려운 변경에 모은다(원칙 P1·P2·P3, P6).

## 전제

팀 3명([context.md](../context.md)). 인원이 늘거나 일반 공개 뒤 사용자가 늘면 다시 본다.

## 버린 대안

- 모든 PR 승인 1명(이전 관행): 작은 수정까지 기다리게 된다.
- 위험 영역 승인 2명: 3명 팀에서는 한 명만 자리를 비워도 멈춘다.

## 따라오는 일

경로 기준으로 승인을 강제하려면 `CODEOWNERS`와 브랜치 보호 설정이 필요하다(후속 이슈).
